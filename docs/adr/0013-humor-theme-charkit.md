## 결정 (Decision)

1. **아트 테마 = 유머러스** (GDD §1·§15의 Bacon 유머 노선 확정) — 실없는 귀여움: 큰 글린트 눈,
   열린 스마일, 우스꽝 소품(도둑 자루 물음표 패치, 방패의 계란 문양, 파리 혀 내밀기 등).
2. **캐릭터 공통 킷** — `ui/views/charKit.ts`: 굵은 웜브라운 외곽선(OUTLINE) · 2톤 셰이딩
   (`drawBody2Tone`) · 흰자+동공+글린트 눈(`drawEye`) · 열린 스마일(`drawOpenSmile`) · 볼터치.
   상용 캐주얼 게임의 마감 문법을 모든 뷰가 공유 — 스타일 파편화 방지.
3. **손님 다양화** — 절대 번호 해시 조합(체형×눈×입×모자×안경류×소품×색)으로 수백 종의
   서로 다른 손님. 유휴 숨쉬기 애니로 생동감.
4. **무료 에셋 정책** — 라이선스가 깨끗한 외부 에셋은 **폰트(Jua/OFL — 적용됨)·사운드(추후 CC0)**
   에 활용. **캐릭터·배경은 절차적 유지**: 스타일 통일성·번들 예산·컨셉아트 미확정 상태에서의
   유연성 때문. 컨셉아트가 확정되면 `ASSET_MANIFEST`(GDD §14) 경로로 스프라이트 교체 가능 — 절차적
   드로우는 그때 폴백/프로토타입 도구로 남는다.

## 근거 / 결과

- "구리다"의 원인 분해: 점 눈·단색 몸통·외곽선 부재·정지 상태 = 프로토타입 신호. 킷이 이를 계층
  (외곽선→2톤→하이라이트→표정)으로 치환.
- 뷰별 개별 스타일 대신 킷 함수 재사용 → 이후 컨셉아트 반영 시 킷만 갈아끼우면 전체 톤 변경.
- 렌더 비용: 재드로우 횟수는 불변(상태 변화 시에만), 도형 수 +2~4개/캐릭터 — 예산 내.
