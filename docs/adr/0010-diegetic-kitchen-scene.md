## 맥락 (Context)

M0~M4 화면은 어두운 배경에 팬·아이템·손님이 **맥락 없이 떠 있어** 추상적으로 읽혔다. 원인 진단:

1. **무대 부재** — 주방(벽·선반·스토브·카운터)이 안 보임. 오브젝트가 공간에 놓여 있지 않음
2. **열원 비가시** — gas 1.0/brazier 1.3(GDD §6.2)이 숫자로만 존재, 불이 안 보임
3. **아이템 무맥락** — 벽걸이라는 설정(GDD §9)이 표현 안 됨. 미스리드는 칼·방패가 **나란히** 걸려야 성립
4. **1인칭 판타지 미전달** — 손이 노란 타원 2개
5. **조작 비가시** — 탭/홀드/스와이프 3동사를 화면이 안내하지 않음

## 결정 (Decision)

Bacon 톤(무자막·부드러운 도형)을 유지하며 5가지를 표현 계층에만 추가한다:

1. **주방 3단 무대**(`KitchenView`) — 위에서부터 [천장 음영 → 손님 대기열 → **서빙 바** → 타일 벽(아이템 거치판) → 조리 카운터]. 손님은 서빙 바 뒤에 서서 "창구 손님"으로 읽힌다.
2. **열원 시각화**(`StoveView`) — 팬 하단 림을 따라 gas=파란 불꽃 링 / brazier=벌건 숯(플리커 애니). `stageDef.heatSource` 데이터 주도 — **열계수가 눈에 보인다**.
3. **아이템 다이제틱 거치**(`ItemView` 거치판 + `ITEM_POS` 재배치) — 나무 판+금속 걸이 위에 아이템. **칼(wall_right_a)과 방패(wall_right_b)는 나란히**(GDD §9 미스리드 성립). 토치는 화살표와 실루엣이 겹치지 않게 둥근 불꽃+컵으로.
4. **왼손이 다음 계란을 쥔다**(`HandsView.setHeldEgg`) — 재고>0이면 껍데기째 계란, 0이면 빈손. 재고 어포던스 + "깨기" 유도.
5. **무자막 동사 힌트**(`HintView`) — crack=탭 물결, flip=차오르는 파이, serve=튀는 위 화살표. **각 동사 첫 성공까지만** 노출(자연 튜토리얼, GDD §11 "죽어보고 배우기"와 양립).

## 근거 (Rationale)

- 규칙·수치(`balance.ts`)는 무변경 — 순수 표현 패스라 ADR-0009 연속 개발 범위.
- 무대·불꽃·힌트 전부 절차적 도형(불꽃 ~10개·힌트 ≤5개/frame)이라 성능 예산(60fps) 내.
- 힌트를 픽토그램으로 한 것은 Bacon의 무자막 원칙 + 로컬라이즈 비용 0.

## 대안 (Alternatives)

- **텍스트 튜토리얼 오버레이** — 명확하지만 Bacon 톤 파괴 + 로컬라이즈 부담. 기각.
- **배경 raster 일러스트** — 통일감·번들 예산·오프라인 재현성에서 절차적에 밀림(ADR-0009). 기각.
- **컷씬 튜토리얼** — 아케이드 즉시성(GDD §1)과 배치. 기각.

## 결과 (Consequences)

- `CounterView` → `KitchenView`로 대체(삭제). `GameScene.create`가 스테이지 정의를 **먼저** 파싱(스토브가 heatSource 필요).
- 힌트 소멸 플래그(cracked/flipped/servedOnce)는 씬 로컬 — 세션 저장 안 함(재시작 시 다시 보임, 의도).
- M5 야간(열화상)은 `KitchenView`/`StoveView`의 팔레트 스왑으로 자연 확장.
- 부수 수정: 씬 재시작 시 `smokeFailing` 미리셋 버그(RETRY 후 스모크 실패 무시) 수정.
